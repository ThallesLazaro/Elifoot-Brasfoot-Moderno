# ⚽ O Brasfoot e Elifoot da nova geração

**Goooool.net** é um jogo moderno de técnico de futebol para quem gosta de clássicos como **Brasfoot** e **Elifoot**.

O projeto já está **estável e jogável**. Neste momento, o principal trabalho está concentrado na atualização do banco de dados, substituindo informações antigas por dados atuais do futebol do mundo real.

## 🌐 Jogue agora

### [Acessar Goooool.net](https://goooool.net)

O jogo funciona diretamente pelo navegador, sem precisar baixar ou instalar.

## ✅ Estado atual do projeto

- Versão principal estável;
- jogo disponível para acesso público;
- banco de dados em atualização contínua;
- clubes e jogadores sendo revisados;
- elencos e demais informações sendo aproximados da realidade atual;
- correções aplicadas somente após a confirmação dos dados.

As atualizações do banco de dados são feitas gradualmente. Por isso, alguns clubes ou jogadores ainda podem apresentar informações antigas enquanto a revisão estiver em andamento.

## 🎮 Sobre o Goooool.net

A proposta do Goooool.net é trazer a experiência dos tradicionais jogos de técnico de futebol para uma plataforma mais moderna, acessível e fácil de usar.

O objetivo é permitir que o jogador assuma o comando de um clube e viva a experiência de um técnico de futebol diretamente pelo navegador.

## 📊 Banco de dados do mundo real

A etapa atual do desenvolvimento é dedicada principalmente à atualização de:

- clubes;
- jogadores;
- elencos;
- posições;
- avaliações;
- transferências e outras informações que mudam com o tempo.

O objetivo é manter o jogo cada vez mais próximo do futebol real, sem comprometer a estabilidade já alcançada pelo projeto.
